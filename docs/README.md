## Status

This repository is retained as a legacy Java comparison lab alongside the modern `xpeedopr` implementation. It demonstrates Java 21, JSP, JPA/Hibernate, MySQL, Flyway, Maven WAR packaging, Tomcat deployment, and Docker-based local orchestration. It is not a production service.

The documents describe current state only. They do not change source, dependencies, configuration, credentials, container behavior, or Git history.
