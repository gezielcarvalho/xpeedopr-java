# Project charter

## Purpose

Demonstrate a traditional Java web application for a helpdesk ticket domain using JSP, JPA/Hibernate, MySQL, Flyway migrations, and Tomcat packaging.

## Portfolio role

Keep this repository as a legacy-stack comparison to the .NET/React/Angular XpeedOPR demonstration. It supports conversations about Java web-application fundamentals, persistence, migrations, WAR delivery, and modernization trade-offs.

## Current scope

- Ticket listing and creation domain flow with status values.
- JPA/Hibernate persistence and MySQL schema migration assets.
- Maven WAR packaging and Tomcat deployment guidance.
- Docker Compose services for MySQL, Flyway, and the web application.

## Outside current scope

- Complete ticket CRUD, validation, user authentication, authorization, REST endpoints, and application tests.
- Modern framework migration, managed deployment, observability, or support operations.
- Approved secrets management or production configuration.
